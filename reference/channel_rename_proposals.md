# Read the reviewed channel rename proposals

Read the reviewed channel rename proposals

## Usage

``` r
channel_rename_proposals(workspace = c("organiser", "community"), path = NULL)
```

## Arguments

- workspace:

  Either `"organiser"` or `"community"`.

- path:

  Optional path to the proposals CSV, for testing.

## Value

A data frame of `old`/`new` channel names for that workspace.
