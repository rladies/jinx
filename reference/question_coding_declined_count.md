# Count coding questions Jinx declined

Count coding questions Jinx declined

## Usage

``` r
question_coding_declined_count(rows)
```

## Arguments

- rows:

  Data frame from
  [`question_log_query()`](https://rladies.github.io/jinx/reference/question_log_query.md).

## Value

Integer count of `outcome == "coding_declined"` rows.
